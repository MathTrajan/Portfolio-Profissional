## ✅ Funcionalidades do Site

### 🎨 Design & Visual
- **Dark theme** com fundo `#0a0e1a`, acentos azul elétrico `#4f8ef7` e roxo `#7c3aed`
- **Background animado** com gradientes radiais e grid de pontos
- **Tipografia premium**: Inter (texto) + Fira Code (código)
- **Glassmorphism** no navbar ao rolar
- **Animações CSS** suaves (fade-up, float, spin, pulse)

### 📱 Responsividade
- Layout totalmente responsivo (mobile / tablet / desktop)
- Menu hamburger em dispositivos móveis
- Breakpoints em 480px, 768px e 1024px
